# CycleMate

Android app for loading OCM and adding a "You-are-here-button".

![Screenshot_20250831_173851](https://github.com/user-attachments/assets/59e23626-620d-45d3-8652-98a4959b7cb7)

## SetUp
Add gradle.properties:

```
# AndroidX aktivieren
android.useAndroidX=true
android.enableJetifier=true
org.gradle.jvmargs=-Xmx2048m -Dfile.encoding=UTF-8

THUNDERFOREST_KEY=<add your key here>
```
### Thunderforest Key
You get your Thunderforest key by creating an account here `https://www.thunderforest.com/docs/apikeys/`
